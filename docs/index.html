Frequently Asked Questions

Everything you need to know about setup, privacy, and performance.

Instead of bundling a full 300MB copy of Chromium and Node.js (like Electron apps do), Overtone is built using Neutralinojs, which taps directly into Windows' native WebView2 engine and lightweight compiled C# Win32 helpers.

No! The app connects via the official Spotify Web API using PKCE OAuth and works seamlessly with both Free and Premium Spotify accounts.

No! The app is completely zero-configuration out of the box. Just download, launch, and click "Login with Spotify" to link your account in 1 click. Power users can still provide a custom Client ID in Settings if desired.

Yes, 100%. The app uses standard Spotify OAuth 2.0 PKCE. Tokens are stored securely in Windows Credential Manager (`secure_store.exe`) using Windows DPAPI encryption. No secret keys or credentials are ever sent to external servers.

Our 4-level scraper fallback pipeline automatically races Lrclib, NetEase, Musixmatch, and Lyrics.ovh. If all fail, a non-intrusive manual search panel slides in allowing you to search manually or paste a local .lrc file!
